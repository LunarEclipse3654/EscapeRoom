# 마지막 신호 확장판 v2.4 — 검증 기록

## v2.4 바닥 물건·물체 보기·그림 UI

검증일: 2026-10-18. 모델·배치·바닥 소유권 자동 검증은 이 맵 34개, 두 맵 합계 65개가 통과했습니다. Q 내려놓기와 E 회수, 선택 칸의 빈손 전환, 떨어진 물건의 저장·복원, 보상 갱신 중 복제 방지, 장착 부품 우선, 손상 좌표 복구, 초기화를 다룹니다.

Chrome에서 Q/E를 실제 입력하고 원본 종이 중복 없음·동일 바닥 위치 복원·여러 물건의 간격·벽/가구/닫힌 문 경계를 검증했습니다. 가려진 물건은 E로 줍지 못하며, 모달·텍스트 입력·드래그 중 Q는 무시됩니다.

미완성 사진·성도는 현재 순열을 그대로 그립니다. 사진 18개·성도 12개 표본 픽셀이 원래 조각 위치와 일치했고, 미완성 그림이 완성본과 다름을 확인했습니다. 손의 그림은 1024 해상도와 실제 비율을 유지합니다. PC·390×844 화면에서 손의 그림이 화면 밖으로 잘리거나 핫바에 가려지던 부분을 조정했습니다.

그림 메뉴·장치·설정·기록·가방의 visible UI 텍스트와 반응 문구가 표시되지 않는 것을 검사했습니다. 단서 그림 속 문자와 기기의 물리 눈금은 유지합니다. R 물체 보기에서는 HUD·가방·헤더·하단 버튼이 보이지 않습니다. 사진/지도 조립, 원판 가장자리 직접 회전, 필름 회전과 연구실 그림의 기록 펼치기가 동작합니다. 유리 상판의 마름모는 SVG 경로로 그립니다.

390×844 실제 터치 이벤트로 내려놓기 그림→손 그림 회수, 가방 이동·취소, 실제 장치에 물건 드래그, 물체 바깥 탭 닫기, 이동 복귀를 확인했습니다. 터치에서는 Pointer Lock 요청이 0건입니다. Asteria의 미완성 성도 참조 그림이 네 칸 격자로 보이고 각 조각 너비가 실제로 유지되는 것도 확인했습니다.

수정용 소스와 최종 단일 HTML 둘 다 실제 UI 입력으로 전체 퍼즐 체인을 풀고 마지막 출구를 걸어 나갔습니다. 진행 플래그를 직접 완료로 바꾸지 않았습니다. 드래그 오답·취소·소비·저장 복원, 원판 그림 회전, 마지막 기록과 초기화도 확인했습니다. 두 최종 파일은 비문서 네트워크 요청을 차단한 상태에서도 완주했고 추가 게임 자산 요청과 JavaScript 오류가 0건이었습니다. 별도 오프라인 Q→E→R·그림 품질 설정·마우스 고정 복귀도 통과했습니다.

반복 점검에서 핫바에 초점이 남으면 Esc가 전달되지 않던 입력, 화면 식별 속성과 성도 조각 선택자의 충돌, 참조 성도의 격자를 덮던 헤더 스타일을 수정했습니다. 손의 그림은 변경 시에만 갱신하고, 바닥 물건은 회수할 때 기하·재질·그림을 해제합니다. 이전 품질 조절과 렌더링 제한도 유지합니다.

사전 정보를 모르는 독립적인 사람의 난이도 시험, 실제 휴대전화와 Windows 실행 파일 검증은 아직 별도입니다. 아래는 이전 개정의 검증 이력입니다.

## v2.3.1 R키·시점 복귀 검증

검증일: 2026-10-18. R은 선택한 보관함 물건이 아닌 실제 손에 든 물건을 펼칩니다. 탐색 중과 가방에서 사용할 수 있으며, 빈손·키 반복·수정키·텍스트 입력·열린 조사 창·드래그 중에는 새 물건 보기를 열지 않습니다.

Chrome의 실제 Pointer Lock API로 검증했습니다. 인벤토리를 I·Esc·닫기 버튼으로 닫기, 자료·수첩 닫기, 일시정지에서 계속하기 뒤에는 추가 클릭 없이 고정을 다시 획득하고 마우스 이동으로 시점이 바뀝니다. 물건 보기↔가방, 수첩→가방, 조작법→일시정지 등 창 사이를 옮길 때는 고정을 요청하지 않습니다. 비동기 고정 요청 중 창이 다시 열리는 경우도 탐색 상태를 확인합니다. 390×844 터치 환경에서는 고정을 요청하지 않고 터치 조작을 복원합니다.

두 맵 소스와 최종 단일 HTML에서 R·닫기·실제 고정 복귀를 확인했습니다. 런타임·고정 요청 오류는 없었습니다. 상태·배치 자동 검증은 두 맵 합계 49개가 통과했습니다. 아래는 이전 개정의 기록입니다.

브라우저가 고정을 허용하지 않는 환경에서는 화면 클릭 안내와 드래그 시점 조작을 유지합니다. API의 사용자 입력 및 브라우저 제한은 [MDN 문서](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestPointerLock)를 참고하세요.

## v2.3 한 손·36칸 인벤토리 검증

검증일: 2026-10-18. 보관함 27칸(3×9)과 빠른 슬롯 9칸을 분리했습니다. 선택된 빠른 슬롯 한 칸만 손에 들고 빈 칸은 빈손입니다. 화면에는 오른손 하나와 물건 하나만 그리며, 가방·조사 창·드래그 중에는 이 손을 숨깁니다. 드래그 커서도 물건 하나만 표시합니다. 숫자키 1–9, 휠 순환, 빈손 선택, 칸 이동·교환, Shift 빠른 이동, 배치와 선택 칸 저장을 확인했습니다.

모델 13개와 공통 배치 12개, 총 25개 자동 검증이 통과했습니다. 공통 배치 검증은 소유권 보존, 소비 후 빈손, 잘못된 저장, 기존 선택 이관, 중복 방지, 취소·교환·초기화를 다룹니다. Chrome에서 실제 퍼즐 조작과 드래그로 전체 체인을 풀고 출구를 걸어 나갔습니다. 진행 상태를 직접 완료로 바꾸지 않았습니다. 14개 물건이 모인 상태의 36칸 배치·한 손 전환·재사용 도구·부품 소비·저장 복원과 텍스트 입력 중 숫자키/휠의 비간섭을 확인했습니다.

390×844 실제 터치 이벤트로 길게 눌러 집기, 보관함 이동, 취소, 빈손, 보관함의 열쇠를 서랍으로 직접 놓기를 검증했습니다. 가방이 장치 그림을 가리던 모바일 배치를 위 정렬로 수정했고, 핫바를 클릭한 뒤 숫자키가 무시되던 입력과 도구 사용 중 선택이 되돌아가던 동기 갱신을 수정했습니다. 데스크톱·모바일의 손 크기와 UI를 시각적으로 확인했습니다.

최종 단일 HTML은 추가 게임 자산 요청 0건이며, 네트워크를 끊은 상태의 종이 회수·사진 조립·열쇠 드래그와 저장 복원도 통과했습니다. JavaScript 오류는 없었습니다. 아래는 이전 개정의 검증 이력입니다.

## v2.2 회수·인벤토리 개정

종이 6종은 현장에서 E로 회수되며 조사 창을 열지 않고 가방으로 들어갑니다. 사진은 미완성 상태로도 회수해 가방에서 조립합니다. 회수한 종이는 3D 공간에서 사라지고 조사 대상에서도 제외됩니다. 서랍·시계·금고의 쪽지·사진 4종도 소지품으로 옮깁니다. 기존 v2 저장에서 확인했던 종이는 새 인벤토리로 이관되며, 새 저장은 ‘본 자료’와 ‘회수한 자료’를 구분합니다.

기존 11개에 종이 회수·중복·초기화 및 저장 이관 검증을 추가한 모델 검증 13개가 통과했습니다. 수첩에서 소지품의 들기·사용을 제거하고 I 가방과 Tab 관측 수첩을 분리했습니다. 열쇠·필름·UV 램프·부품·렌즈·두 투명판은 직접 드래그해 적용합니다. 필름을 회수한 표 아이템에 놓아 겹칠 수도 있습니다. 선택만으로 처음 UV 단서가 드러나지 않도록 실제 적용 이력을 확인합니다.

Chrome에서 E 종이 회수(창 없음·월드 제거), 가방에서 사진 조립, 모든 도구의 포인터 드래그, 3D 서랍에 열쇠 놓기, 회수한 표와 필름 겹치기, 오답·바깥 놓기·Esc·포인터 취소, 소모 부품 저장 복원 및 실제 출구 이동을 검증했습니다. 가방과 빠른 슬롯은 별도의 UI이며 물건은 취소 시 유지됩니다. 모바일에서는 가방을 짧게 밀어 스크롤하고 길게 누른 뒤 끌며, 빠른 슬롯은 좌우로 넘길 수 있습니다.

최종 단일 HTML에서도 같은 전체 진행과 탈출을 통과했습니다. 단일 파일 로드의 추가 자산 요청은 0건이며, 네트워크를 끊은 상태의 회수·인벤토리·저장 복원을 확인했습니다. 390×844 실제 터치 이벤트로 열쇠·부품 드래그, 잘못 놓기·취소·스크롤·길게 눌러 끌기를 검증했습니다. 가방에 가려진 3D 대상으로 놓기와 가방의 의도적인 30fps가 자동 품질을 잘못 낮추지 않는 것도 확인했습니다. 브라우저 오류는 없었습니다.

아래 v2.1 기록은 단서 연결 개정의 검증 이력입니다. 실제 사람의 사전 정보 없는 플레이 테스트와 Windows 실행 파일 검증은 수행하지 않았습니다.

검증일: 2026-10-18. 대표 맵은 해안 관측소 1개이며, v2의 단서 연결을 v2.1에서 개정했습니다. 저장 형식과 기존 정답은 유지합니다. 아래 기록은 검증 범위를 구분하며 이전 버전의 브라우저 결과를 최종판 결과로 간주하지 않습니다.

v2.1에서는 책장 사진과 실제 책 홈, 해안 관측도와 밤 사진·망원경, 통신 형식과 수신기, 인장과 문자 원판, UV 그림과 배전반, 유압관과 문 잠금장치를 같은 형태로 연결했습니다. 회전 원판의 시계 방향 움직임 및 안쪽→바깥쪽 대응을 실제 SVG 위치로 검증했습니다. 물리 장면과 조사 창의 UV·관측·수신 표시는 현재 도구와 좌표·주파수를 따릅니다. 발견한 원자료는 수첩에 남습니다. 자세한 추론 근거는 `CAUSALITY.md`에 있습니다.

개정 후 모델 검증 11개, 조사 대상 18개의 접근 검사, UV·수신기·망원경·유압·가로 다이얼 회귀 검증이 통과했습니다. Chrome에서 폴더판과 최종 단일 HTML판을 각각 실제 UI 입력으로 완주하고, 완료 후 이어하기·초기화·메모 복원까지 다시 확인했습니다. 단일 HTML의 추가 게임 자산 요청은 0건이며 네트워크를 끊은 상태의 조작도 통과했습니다. JavaScript 오류는 없었습니다. 아래의 터치 검증은 v2에서 수행한 범위이며 이번 v2.1은 390×844 UI 배치·수첩 복원을 재확인했습니다. 독립적인 사람의 사전 정보 없는 플레이 테스트는 수행하지 않았습니다.

## 완료한 자동 검증

상태 모델 테스트 **11개가 통과**했습니다. `npm test` 또는 `node --test tests/model.test.cjs`로 다시 실행할 수 있으며 테스트에는 정답이 포함됩니다.

- 사진부터 실제 탈출 완료까지 전체 진행, 물리적 선행 조건과 소지품 변화
- 올바른 추론을 단서 열람 여부로 제한하지 않는 동작
- 각 퍼즐의 오답과 잘못된 형식·범위·빈 배열 입력 거부
- 3×3 점등판의 자기 칸·상하좌우 토글과 가로 경계 처리
- 압력 관계식의 1~6 범위 내 유일해
- 자동 수첩에 해독 답이나 다음 행동 대신 원자료 참조만 기록
- 반복 조작 시 아이템·기록 중복 방지와 장착 부품의 재생성 방지
- **22개 저장 지점**의 상태를 정확히 복원하고 각각 다시 완주
- v1 저장 보존, v2와 분리, 손상·호환 불가·차단된 저장소 처리
- 저장 데이터가 손상되어도 획득·장착·배치한 유일 아이템을 잃지 않는 복구
- 시간, 직접 쓰는 메모, 손에 든 물건, 구독 알림과 새 게임 초기화

정적 3D 검증에서는 조사 대상 **18개**의 고유 ID와 상태별 장면 갱신을 확인했습니다. 충돌 경계로 나눈 연결된 보행 영역을 탐색하고 조준 광선으로 각 조사 대상에 닿는 위치가 있음을 확인했습니다. 이는 실제 브라우저에서 모든 이동과 클릭을 검증하는 과정과 별도입니다.

## 완료한 브라우저 검증

Chrome의 수정용 폴더판에서 **확장판 v2의 전체 진행을 통과**했습니다. 충돌상 유효한 위치에서 실제 E 입력으로 18개 조사 대상을 각각 열고, 화면의 퍼즐 조작과 소지품 선택·사용으로 전체 체인을 풀었습니다. 모델에 정답을 직접 넣어 진행 상태를 바꾸는 방식은 사용하지 않았습니다.

필름 회전, 벽시계 04:35, 오답 후 재시도, 도구 장착, 두 투명판의 실제 배치, 문 열기와 통로를 걸어 나가 완료 화면에 도달하는 흐름을 확인했습니다. 완료 후 새로고침에 따른 상태 복원과 새 게임의 원자료 기록 초기화도 확인했습니다. 이 검증에서 JavaScript 오류는 발견되지 않았습니다.

최종 단일 HTML판에서도 같은 전체 체인과 완료 후 재개·새 게임 검증을 통과했습니다. 단일 파일을 불러올 때 추가 자산 요청이 0건임을 확인했고, 이후 브라우저의 네트워크를 끊은 상태에서 이동·조사·수첩·설정·일시정지를 확인했습니다.

390×844 모바일 에뮬레이션에서 실제 터치 이벤트로 이동 버튼 누르기·떼기, 화면 드래그, 드래그 직후 조사, 사진 창 열기, 수첩 메모, 긴 창 스크롤 후 닫기를 검증했습니다. 가로 넘침과 JavaScript 오류는 없었습니다. 직접 쓴 메모의 새로고침 복원도 확인했습니다. 실제 휴대전화에서의 검증은 수행하지 않았습니다.

## 반영한 사용성·설계 수정

- 오브젝트 이름을 알려주는 조사 라벨, 진행 목표, 단계별 H 힌트와 정답 안내 제거
- 잠금 장치와 풀이에 필요한 자료를 서로 다른 물리적 위치에 배치
- 수첩에는 발견한 원자료를 보관하고 해석은 플레이어가 직접 메모하도록 구성
- 미완성 사진을 수첩에서 완성 이미지로 열어 정답을 미리 보는 우회 방지
- 수신 전에는 무전기의 원문이 노출되지 않도록 분리
- 필름과 두 투명판을 본 기록 및 배치 전 원자료 보존
- 도구를 소지품에서 들고 대상에 사용하는 상호작용으로 통일
- 소모된 부품의 재획득·중복과 저장 복원 시 아이템 손실 방지
- 별도 이미지 해석 검토에서 발견한 논리 범위 누락을 원자료의 눈금으로 보완
- 관계없는 무늬 사이의 오연결, 도면의 읽는 순서와 작은 나침반의 가독성 수정
- 드래그 직후 터치 조사가 누락되지 않도록 누름 이벤트에서 처리

## 유지·적용한 최적화

- 플레이 렌더링 최대 60fps, 메뉴·퍼즐 배경 최대 30fps
- 숨겨진 페이지의 렌더링 중단과 오디오 일시 중단
- 자동 품질에서 성능 감지에 따른 픽셀 비율 하향 조절
- 낮음 품질에서 실시간 그림자 제거, 품질별 그림자 해상도 제한
- 상태가 바뀔 때 정적 그림자를 다시 계산
- 반복 도형·재질 공유, 로컬 원자료 그림 캐시, 조사 감지 주기 제한
- 외부 이미지·모델·폰트·오디오 요청 없이 오프라인 실행

위 fps 값은 렌더링 상한이며 모든 컴퓨터에서 해당 성능을 보장하는 벤치마크 결과가 아닙니다.
