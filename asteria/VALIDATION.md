# Asteria v1.3 — 검증 기록

## v1.3 바닥 물건·물체 보기·그림 UI

검증일: 2026-10-18. 모델·배치·바닥 소유권 자동 검증은 이 맵 31개, 두 맵 합계 65개가 통과했습니다. Q 내려놓기와 E 회수, 선택 칸의 빈손 전환, 떨어진 물건의 저장·복원, 보상 갱신 중 복제 방지, 장착 부품 우선, 손상 좌표 복구, 초기화를 다룹니다.

Chrome에서 Q/E를 실제 입력하고 원본 종이 중복 없음·동일 바닥 위치 복원·여러 물건의 간격·벽/가구/닫힌 문 경계를 검증했습니다. 가려진 물건은 E로 줍지 못하며, 모달·텍스트 입력·드래그 중 Q는 무시됩니다.

미완성 사진·성도는 현재 순열을 그대로 그립니다. 사진 18개·성도 12개 표본 픽셀이 원래 조각 위치와 일치했고, 미완성 그림이 완성본과 다름을 확인했습니다. 손의 그림은 1024 해상도와 실제 비율을 유지합니다. PC·390×844 화면에서 손의 그림이 화면 밖으로 잘리거나 핫바에 가려지던 부분을 조정했습니다.

그림 메뉴·장치·설정·기록·가방의 visible UI 텍스트와 반응 문구가 표시되지 않는 것을 검사했습니다. 단서 그림 속 문자와 기기의 물리 눈금은 유지합니다. R 물체 보기에서는 HUD·가방·헤더·하단 버튼이 보이지 않습니다. 사진/지도 조립, 원판 가장자리 직접 회전, 필름 회전과 연구실 그림의 기록 펼치기가 동작합니다. 유리 상판의 마름모는 SVG 경로로 그립니다.

390×844 실제 터치 이벤트로 내려놓기 그림→손 그림 회수, 가방 이동·취소, 실제 장치에 물건 드래그, 물체 바깥 탭 닫기, 이동 복귀를 확인했습니다. 터치에서는 Pointer Lock 요청이 0건입니다. Asteria의 미완성 성도 참조 그림이 네 칸 격자로 보이고 각 조각 너비가 실제로 유지되는 것도 확인했습니다.

수정용 소스와 최종 단일 HTML 둘 다 실제 UI 입력으로 전체 퍼즐 체인을 풀고 마지막 출구를 걸어 나갔습니다. 진행 플래그를 직접 완료로 바꾸지 않았습니다. 드래그 오답·취소·소비·저장 복원, 원판 그림 회전, 마지막 기록과 초기화도 확인했습니다. 두 최종 파일은 비문서 네트워크 요청을 차단한 상태에서도 완주했고 추가 게임 자산 요청과 JavaScript 오류가 0건이었습니다. 별도 오프라인 Q→E→R·그림 품질 설정·마우스 고정 복귀도 통과했습니다.

반복 점검에서 핫바에 초점이 남으면 Esc가 전달되지 않던 입력, 화면 식별 속성과 성도 조각 선택자의 충돌, 참조 성도의 격자를 덮던 헤더 스타일을 수정했습니다. 손의 그림은 변경 시에만 갱신하고, 바닥 물건은 회수할 때 기하·재질·그림을 해제합니다. 이전 품질 조절과 렌더링 제한도 유지합니다.

사전 정보를 모르는 독립적인 사람의 난이도 시험, 실제 휴대전화와 Windows 실행 파일 검증은 아직 별도입니다. 아래는 이전 개정의 검증 이력입니다.

## v1.2.1 R키·시점 복귀 검증

검증일: 2026-10-18. R은 선택한 보관함 물건이 아닌 실제 손에 든 물건을 펼칩니다. 탐색 중과 가방에서 사용할 수 있으며, 빈손·키 반복·수정키·텍스트 입력·열린 조사 창·드래그 중에는 새 물건 보기를 열지 않습니다.

Chrome의 실제 Pointer Lock API로 검증했습니다. 인벤토리를 I·Esc·닫기 버튼으로 닫기, 자료·수첩 닫기, 일시정지에서 계속하기 뒤에는 추가 클릭 없이 고정을 다시 획득하고 마우스 이동으로 시점이 바뀝니다. 물건 보기↔가방, 수첩→가방, 조작법→일시정지 등 창 사이를 옮길 때는 고정을 요청하지 않습니다. 비동기 고정 요청 중 창이 다시 열리는 경우도 탐색 상태를 확인합니다. 390×844 터치 환경에서는 고정을 요청하지 않고 터치 조작을 복원합니다.

두 맵 소스와 최종 단일 HTML에서 R·닫기·실제 고정 복귀를 확인했습니다. 런타임·고정 요청 오류는 없었습니다. 상태·배치 자동 검증은 두 맵 합계 49개가 통과했습니다. 아래는 이전 개정의 기록입니다.

브라우저가 고정을 허용하지 않는 환경에서는 화면 클릭 안내와 드래그 시점 조작을 유지합니다. API의 사용자 입력 및 브라우저 제한은 [MDN 문서](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestPointerLock)를 참고하세요.

## v1.2 한 손·36칸 인벤토리 검증

검증일: 2026-10-18. 보관함 27칸(3×9)과 빠른 슬롯 9칸을 분리했습니다. 선택된 빠른 슬롯 한 칸만 손에 들고 빈 칸은 빈손입니다. 화면에는 오른손 하나와 물건 하나만 그리며, 가방·조사 창·드래그 중에는 이 손을 숨깁니다. 드래그 커서도 물건 하나만 표시합니다. 숫자키 1–9, 휠 순환, 빈손 선택, 칸 이동·교환, Shift 빠른 이동, 배치와 선택 칸 저장을 확인했습니다.

모델 12개와 공통 배치 12개, 총 24개 자동 검증이 통과했습니다. 같은 배치·드래그 구성요소를 기존 맵과 공유하며 맵별 저장 키를 분리합니다. Chrome에서 실제 E 회수, 가방에서 지도 조립, 자료 드래그, 다섯 퍼즐, 마지막 기록, 출구까지 전체 진행을 통과했습니다. 완료 후 저장 복원·초기화와 390×844 화면의 9열 배치도 확인했습니다.

최종 단일 HTML의 추가 게임 자산 요청은 0건입니다. 네트워크를 끊고 지도 회수·조립·망원경에 자료 드래그 및 저장 복원을 확인했습니다. JavaScript 오류는 없었습니다. 공통 구성요소의 실제 모바일 터치 이동·취소·장치 놓기는 기존 맵에서 함께 검증했습니다. 아래는 이전 개정의 검증 이력입니다.

## v1.1 회수·인벤토리 개정

성도·일지·대조표·연구실 설계도는 E로 회수하면 창 없이 소지품으로 들어가고 월드에서 사라집니다. 성도는 미완성 조각 상태로 회수하며 가방에서만 펼쳐 조립합니다. 미완성 아이콘과 참조 화면에 완성본을 노출하지 않습니다. 설계도를 회수하는 것만으로 비상구가 열리지는 않습니다. 기존 저장에서 확인했던 종이는 소지품으로 이관합니다.

모델 검증은 회수·중복·회수와 열람의 구분·저장 이관·연구실 조건을 더해 12개가 통과했습니다. Chrome에서 실제 E 회수와 창 없음·월드 제거, 가방에서 조립, 키보드 집기·놓기, 390×844 터치 가방 확인을 검증했습니다. 자료를 장치에 끌어 놓으면 원자료를 옆에 펼치며 정답이나 퍼즐 값을 자동 입력하지 않습니다.

폴더판과 최종 단일 HTML판 모두 네 종이 회수·자료 드래그·다섯 퍼즐·설계도를 가방에서 꺼내 마지막 기록 읽기·실제 출구 이동을 통과했습니다. 저장·초기화·모바일 배치도 확인했습니다. 단일 HTML의 추가 자산 요청은 0건이며 네트워크를 끊은 회수·가방·저장 복원도 통과했습니다. 브라우저 오류는 없었습니다. 아래는 초기판의 공간·퍼즐 검증 이력입니다.

검증일: 2026-10-18. 첨부 기획서의 첫 번째 테마만 추가했습니다. 실제 이용자를 대상으로 한 난이도·소요 시간 측정은 수행하지 않았습니다.

## 퍼즐·저장

`node --test tests/model.test.cjs`의 9개 검증이 통과했습니다. 다섯 퍼즐 완주, 오답과 범위, 자유로운 관측 순서, 27:49의 하루 넘김, 첫 빛과 네 번째 빛의 다른 종착점, 별자리 180도 대응, 모든 주요 저장 지점에서 복원 후 완주, 손상·차단된 저장소, 메모·초기화를 검증합니다. 정답은 테스트와 별도 공략에만 있습니다.

## 공간

충돌을 포함한 보행 영역을 탐색했습니다. 처음에는 관측실과 자료실만 연결됩니다. 시계 해금 후 기계실, 별자리 벽 해금 후 비밀 연구실, 마지막 기록 열람 후 출구 통로에 닿습니다. 각 단계에서 잠긴 공간으로 우회할 수 없으며 조사 대상 10개 모두 유효한 위치에서 3.1m 이내로 조준할 수 있습니다.

실제 기계실과 조사 도면은 같은 광선·거울·별 데이터에서 나옵니다. 도면은 높이를 포함한 투영으로 윗줄과 아랫줄의 별을 구분합니다. 광선 네 개를 같은 굵기로 표시하여 추적할 빛을 자료실 일지에서 판단하도록 했습니다. 별자리 그림은 같은 원본 패턴을 실제로 반 바퀴 돌립니다.

## 브라우저 완주

Chrome에서 수정용 폴더판과 단일 HTML판을 각각 처음부터 탈출까지 검증했습니다. 충돌상 유효한 위치로 카메라를 배치하고 실제 E 입력으로 조사한 뒤, 모든 정답은 화면의 퍼즐 조작으로 입력했습니다. 진행 플래그를 직접 켜는 방식으로 완주하지 않았습니다. 최종 출구는 이동 키로 걸어 나갔습니다.

지도 미완성 시 수첩에 완성본이 노출되지 않음, 틀린 망원경 각도, 관측 4건과 중복 방지, 시계 오답, 네 번째 빛 종착점 오답, 별자리 오답 후 재시도, 마지막 기록 이후 출구, 완료 후 새로고침과 이어하기, 새 게임 초기화, 직접 쓴 메모 복원을 확인했습니다. JavaScript 오류는 없었습니다.

## 오프라인·터치

단일 HTML 로드 시 추가 게임 자산 요청은 0건이었습니다. 이후 브라우저 네트워크를 끊고 수첩, 메모, 일시정지, 품질 변경과 재개가 동작했습니다. 낮음 품질에서 그림자가 꺼지는 것도 확인했습니다.

390×844 모바일 에뮬레이션에서 실제 터치 이벤트로 이동 버튼 누르기·놓기, 화면 드래그, 드래그 직후 조사 버튼, 지도 창, 수첩 메모, 긴 창 스크롤 후 닫기를 확인했습니다. 가로 넘침과 JavaScript 오류는 없었습니다. 실제 휴대전화와 Edge의 실행 검증은 수행하지 않았습니다.

## 반복 점검·최적화

완성 지도 사전 노출, 높이가 겹쳐 보이던 거울 도면, 기계에서 미발견 일지를 제공하던 우회, 실제 시계와 UI의 시간 체계 차이, 늘어난 별자리 그림, 실내를 가로지르던 돔 골조, 제목의 어색한 줄바꿈, 중복된 별자리 조작 화면을 수정했습니다.

반복 구조물 888개를 인스턴스로 묶고 기하·재질·그림을 재사용합니다. 플레이 렌더링은 약 60fps, 메뉴·조사 배경은 약 30fps 상한이며, 숨겨진 창은 렌더링과 소리를 중단합니다. 픽셀 비율을 제한하고 자동 품질 조절을 적용합니다. 정적 그림자는 기계의 문·책장·벽이 움직일 때만 다시 갱신합니다.

이 환경의 Chrome 1440×900, DPR 1에서 관측실은 초기 43fps 뒤 60fps, 기계실은 초기 48fps 뒤 60fps로 관찰했습니다. 그리기 호출은 각각 35회·72회였습니다. 이는 한 환경의 측정이며 모든 기기에서 같은 성능을 보장하지 않습니다.

## 남은 별도 검증

독립적인 사람의 사전 정보 없는 플레이 테스트, 실제 휴대전화, Windows `.exe` 생성·설치·실행 및 코드 서명은 수행하지 않았습니다. 실행 파일 전환용 구조와 설정을 제공하는 것과 실행 파일 검증은 구분합니다.
