# 사라진 천문학자의 관측소 — Asteria v1.3.0

1927년 아스테리아 관측소에서 사라진 천문학자의 기록을 따라 비밀 연구실과 비상구를 찾는 오프라인 1인칭 3D 방탈출 게임입니다. 첨부한 다섯 맵 기획서의 첫 테마이며, 지도·좌표·시각·광학 경로·별자리의 다섯 퍼즐과 네 공간을 구현했습니다.

## 실행

부모 폴더의 **사라진-천문학자의-관측소.html**을 Chrome 또는 Edge에서 여세요. 인터넷이나 서버가 필요하지 않은 단일 HTML입니다. 수정용 폴더에서는 index.html 또는 start-local.cmd를 엽니다. WebGL을 지원하는 브라우저가 필요합니다.

## 이번 개정

Q로 손에 든 물건을 가까운 안전한 바닥에 내려놓고 E로 다시 줍습니다. 내려놓은 물건의 위치도 저장되며 원래 자리에서 복제되지 않습니다. 가방·핫바와 바닥을 합쳐 물건 하나당 실제 소유권은 하나입니다. 벽·가구·닫힌 문 너머로 내려놓거나 줍지 않습니다.

미완성 사진과 성도도 현재 조각 배치 그대로 손에 보입니다. 물건의 비율과 문양을 유지하고 고해상도 그림을 재사용합니다. R로 자세히 보면 물체만 표시합니다. 사진·성도는 조각을 직접 바꾸고, 원판은 왼쪽 또는 오른쪽 가장자리를 눌러 회전합니다. 겹친 필름은 판을 눌러 회전하고, 연구실 설계도는 그림을 눌러 마지막 기록을 펼칩니다.

메뉴·가방·조사·설정·장치 조작 UI는 그림으로 표시합니다. 종이에 인쇄된 단서와 기기의 문자·숫자 눈금은 물건 표면에 남습니다. 열림·실패·회수의 상태 문구는 효과음으로 바꿨습니다. 보이는 버튼 글자는 없고 접근성 이름은 유지합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| W A S D / ↑ ↓ | 이동 |
| 마우스 / ← → | 둘러보기 |
| Shift | 빠르게 이동 |
| E | 종이·바닥 물건 회수 / 고정 장치 조사 |
| Q | 현재 손에 든 물건 바닥에 내려놓기 |
| 1–9 / 마우스 휠 | 손에 들 핫바 칸 선택, 빈 칸은 빈손 |
| R | 손에 든 물건만 펼치기 / 펼친 물건 닫기 |
| I | 인벤토리, 물체 보기에서 가방으로 돌아가기 |
| Tab | 관측 기록·직접 쓰는 메모 |
| Esc | 물체·창 닫기 / 일시정지 |
| Shift+클릭 | 보관함 ↔ 핫바 빠른 이동 |

가방 그림은 소지품, 수첩 그림은 기록, 두 세로선은 일시정지, 아래 화살표와 바닥 그림은 내려놓기입니다. 눈 그림은 선택한 소지품 살펴보기입니다. 메뉴의 문·화살표는 시작, 삼각형은 계속하기, 집은 시작 화면, 되돌림 화살표는 새 게임입니다. 설정은 상자(품질)·스피커(소리)·마우스(감도)·흔들림 그림 순입니다.

가방은 27칸(3×9) 보관함과 9칸 핫바로 구성합니다. 선택한 핫바 한 칸의 물건 하나만 오른손에 듭니다. 보관함을 누르는 동작은 펼칠 물건만 고르며 장착을 바꾸지 않습니다. 물건을 끌어서 빈 칸으로 옮기거나 다른 물건과 교환합니다. 가까운 3D 대상이나 조사 화면에 직접 끌어 놓아 사용합니다. 잘못 놓거나 취소해도 소유품은 유지되며, 실제 장착한 부품만 가방에서 빠집니다.

키보드 드래그는 슬롯에서 Space로 집고 Tab으로 대상에 초점을 옮긴 뒤 Enter로 놓습니다. Esc로 취소합니다. 텍스트 입력 중 R·Q·핫바 전환은 동작하지 않습니다. 물체만 보는 상태는 R·Esc 또는 빈 배경을 눌러 닫습니다. 창을 닫아 탐색으로 돌아오면 추가 클릭 없이 마우스가 다시 고정됩니다. 다른 창으로 이동할 때는 커서를 유지합니다.

터치는 이동 화살표·화면 드래그·손 그림을 사용합니다. 소지품은 길게 누른 뒤 끌며, 아래 화살표 그림으로 손에 든 물건을 내려놓을 수 있습니다. 물체 보기에서는 빈 배경을 눌러 돌아갑니다.

## 저장·성능

진행·소지품·바닥 위치·36칸 배치·선택한 칸·직접 쓴 메모·시점은 자동 저장됩니다. 기존 진행은 유지하며 맵별 저장을 분리합니다. 같은 브라우저와 같은 파일 위치에서 이어서 플레이할 수 있습니다. 단일 HTML·원본 폴더·이후 실행 파일은 실행 위치에 따라 저장소가 다를 수 있습니다.

그림과 재질을 재사용하고, 선택 물건이 바뀔 때만 손의 그림을 갱신합니다. 바닥 물건을 회수하면 기하·재질·그림을 해제합니다. 플레이는 60fps, 메뉴·조사 배경은 30fps 상한이며 숨겨진 창은 렌더링과 소리를 중단합니다. 자동 품질·낮음 품질 그림자 제한을 유지합니다. 이 수치는 모든 기기에서 보장하는 측정값이 아닙니다.

## 원본과 실행 파일 전환

- js/state.js: 퍼즐·소유권·바닥 물건·저장
- js/world.js: 3D 공간·충돌·장치
- js/content.js, js/item-art.js: 단서 그림·현재 조각 배치
- js/ui.js, js/pictorial.js, pictorial.css: 물체 보기·그림 UI
- js/inventory.js, js/inventory-layout.js, inventory.css: 가방·핫바·드래그
- js/hand.js, hand.css, js/ground-items.js: 한 손·바닥 물건 렌더링
- js/app.js: 키·이동·오디오·시점 연결
- desktop/main.cjs, package.json: Electron 실행·Windows 포장

Node.js로 npm test를 실행하면 모델·배치·바닥 소유권을 검사합니다. npm run build:html은 단일 HTML을 다시 만듭니다. 이 두 명령에는 별도 패키지 설치가 필요하지 않습니다. desktop/README.md에 실행 파일 전환 절차가 있습니다. 이번 결과물은 HTML이며 .exe 생성·설치·실행 검증은 수행하지 않았습니다.

전체 정답은 WALKTHROUGH.md에 있습니다. 단서 설계는 PUZZLE_DESIGN.md, 검증 범위는 VALIDATION.md를 참고하세요. 독립적인 사람의 사전 정보 없는 난이도 시험과 실제 휴대전화 시험은 아직 수행하지 않았습니다. 라이선스는 THIRD_PARTY_LICENSES.md에 있습니다.
